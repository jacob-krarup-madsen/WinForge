# Security Policy

## Reporting a Vulnerability
Please do not open a public issue. Instead, open a private security advisory via [GitHub Security Advisories](https://github.com/jacob-krarup-madsen/WinForge/security/advisories/new) or contact the maintainer directly.

## Supported Versions
Only the latest release and the current `main` branch are actively supported.

## Response SLA
We aim to acknowledge reports within 48 hours and provide a remediation plan within 7 days.
