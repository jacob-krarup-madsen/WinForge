# Contributing

Thanks for considering contributing!

## Quick Start
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make your changes and add tests where applicable
4. Ensure builds and tests pass: `dotnet build WinForge.sln` and `dotnet test WinForge.sln`
5. Commit with conventional commits: `feat:`, `fix:`, `docs:`, `chore:`, etc.
6. Push and open a Pull Request

## Development
- Keep changes focused, modular, and well-tested
- Target framework: `net9.0-windows10.0.26100.0`
- Maintain 0-warning compilation on `dotnet build WinForge.sln`
- Update documentation if changing user-facing functionality or scripts

## Code of Conduct
Be respectful and constructive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Questions?
Open an issue or start a GitHub Discussion.
