## [1.0.0] - 2026-09-12

### Added
- Native WinUI 3 desktop client built with Windows App SDK 2.3.1 and .NET 9.
- Package Manager storefront with live Winget integration, search, install, upgrade, and uninstall pipelines.
- Feature Velocity Manager with ViVeTool CLI integration and offline feature catalog.
- System Optimizer featuring 25-phase debloat, telemetry disabling, disk/cache cleaning, memory flushing, and system restore point automation.
- Comprehensive automated xUnit test suite (730+ tests) with zero compiler warnings and zero errors.
- Robust CI/CD workflows: multi-stage build, automated test runner, CodeQL static analysis, and automated GitHub release packaging for `win-x64`.
